多模态驱动的电商服饰细粒度语义增强与智能解析系统

项目简介

本项目旨在构建⼀个"图⽚输⼊+⾃然语⾔查询→细粒度语义增强→专业知识回答"的端到端系统

---

3.1.1 服饰实例分割功能
- 功能描述：对输入图片中的服饰进行精准实例分割
- 输入：RGB格式的商品图片（支持任意尺寸）
- 输出：每个服饰实例的分割掩码、边界框和类别标签
- 支持类别：上衣、裤子、裙子、外套、连衣裙、鞋子、包包、配饰共 8 大类
- 性能要求：单张图片分割时间小于等于 50ms，分割 IoU 大于等于 0.85

3.1.2 语言引导的局部区域定位功能
- 功能描述：根据用户自然语言描述，定位图片中对应的服饰局部区域
- 输入：商品图片 + 自然语言查询（如 "这件衣服的领口"、"袖口的设计"）
- 输出：目标区域的分割掩码和边界框
- 支持区域：领口、袖口、下摆、口袋、肩部、腰部、图案、装饰等所有服饰局部
- 性能要求：区域定位准确率大于等于 92%，定位时间小于等于 30ms

3.1.3 细粒度属性提取功能
- 功能描述：提取指定区域的服饰细粒度属性
- 输入：商品图片 + 目标区域掩码
- 输出：该区域的细粒度属性标签和置信度
- 支持属性：14 大类 200+ 细粒度属性，包括：
  * 面料：棉、麻、丝、羊毛、牛仔、涤纶等
  * 工艺：水洗、刺绣、印花、拼接、褶皱、钉珠等
  * 设计：领型、袖长、版型、风格、图案等
- 性能要求：属性识别准确率大于等于 88%，提取时间小于等于 20ms
